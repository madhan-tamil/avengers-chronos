# Avengers: Project CHRONOS
## The Last Five Seconds

### Mission Brief

S.H.I.E.L.D. has detected unauthorized activity in the
Chronos Archive, a system used to store classified
temporal mission records.

The archive's interface is unstable. Its diagnostic
messages reference a synchronization window, and the
incident logs appear to disagree about the order of
events.

The original operator is missing. The protected mission
record remains sealed.

Your task is to investigate the archive, reconstruct
the relevant sequence of events, and recover the
classified mission record.

### Objectives

- Investigate the anomalous web interface.
- Discover and examine the archive's public evidence.
- Understand the legacy authorization workflow.
- Identify and demonstrate the security flaw.
- Recover the final flag.

### Rules

- Interact only with the challenge instance provided.
- Do not attack the hosting platform or other teams.
- Do not use denial-of-service techniques.
- The challenge is designed to be solved through
  web reconnaissance and controlled HTTP testing.
