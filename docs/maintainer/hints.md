# CHRONOS — Progressive Hints

## Hint 1
The unstable interface is not necessarily making
requests. Inspect the client-side resources.

## Hint 2
The incident reference appears in more than one place.
Look for public metadata and reconstruct the event
timeline using UTC.

## Hint 3
The archive enforces a single-use lease. Compare
sequential redemption with overlapping requests.
Pay attention to when the server checks and updates
the lease state.
